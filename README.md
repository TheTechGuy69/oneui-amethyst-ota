# oneui-amethyst-ota

Update feed for the **One UI 9 port for the Redmi Note 14 Pro+ 5G (`amethyst`)**.
The built-in Software update app (Settings → Software update) reads `ota.json` from this repo:

`https://raw.githubusercontent.com/TheTechGuy69/oneui-amethyst-ota/main/ota.json`

## Format
One entry per device codename:
```json
{
  "amethyst": {
    "version": "0.9.9-rc-27",
    "build": "S928BXXU6EZIF | ported by @thetechguy.69 | rc-27",
    "kernel": "TechAmethyst v1.3 (6.1.172)",
    "date": "2026-10-21",
    "url": "https://downloads.sourceforge.net/project/one-ui-for-amethyst/QuartzROM/QuartzROM-Beta-RC/0.9.9-rc-38/QuartzROM-v0.9.9-rc-38-amethyst-test.zip",
    "size": 7900000000,
    "sha256": "<sha256 of the zip>",
    "wipe": false,
    "changelog": "- ..."
  }
}
```
- `version` is compared as `x.y.z[-rc-N]`, and an rc is older than its release (`0.9.9-rc-38 < 1.0.0`).
- `sha256` is checked on the phone after download. A mismatch means the file is deleted and not offered for flashing.
- The entry is generated by `release.sh` in the build kit (`ota_entry.json`). Never edit `sha256` or `size` by hand.

## Publishing a build
1. Upload the zip to the URL in the entry and check that the download link works.
2. Replace the `amethyst` entry in `ota.json` and push. Phones see it on their next check (daily, or when opening Software update).
